PROJECT: GEMINI CODING AGENT

Gemini Coding Agent is an AI coding assistant built in Python using the
Google Gemini API and function calling. The agent interacts with a codebase
through a controlled set of tools for inspecting, modifying, and executing
code.

CORE CAPABILITIES

- Inspect files and directories
- Read file contents
- Create and modify files
- Execute Python files
- Capture stdout, stderr, and exit codes
- Handle execution timeouts
- Validate working-directory paths
- Iteratively debug coding issues

AGENT ARCHITECTURE

The agent uses a modular architecture with separate components for:

- Conversation management
- Prompt construction
- Tool registration
- Tool execution
- Agent orchestration

A Tool Registry maps available tool names to their Python implementations.
The Tool Executor resolves Gemini function calls, executes the requested tool,
and returns the result to Gemini.

The available tools provide file inspection, file reading, file writing, and
Python code execution capabilities.

PYTHON CODE EXECUTION

Python programs are executed using subprocess with:

- Working-directory control
- Execution timeout handling
- stdout capture
- stderr capture
- Exit-code handling

Execution results are returned to Gemini so the agent can analyze actual
program behavior and errors.

ITERATIVE DEBUGGING

The agent supports an iterative debugging workflow:

Inspect code
→ Execute program
→ Analyze errors
→ Modify code
→ Execute again
→ Verify result

This allows the agent to respond to runtime and syntax errors instead of
simply generating code and assuming it works.

GEMINI FUNCTION CALLING

Gemini determines when a tool is required and generates a function call with
the necessary arguments. The Python application executes the requested tool
and sends the result back to Gemini.

The interaction is:

Gemini → Function Call → Tool → Tool Result → Gemini
