RETRIEVAL-AUGMENTED GENERATION (RAG)

Abhinav has built a Retrieval-Augmented Generation (RAG) pipeline for his Ask Abhinav AI developer portfolio.

The RAG workflow converts portfolio knowledge into chunks, generates vector embeddings, stores those vectors in Pinecone, performs semantic vector search when a recruiter asks a question, retrieves relevant portfolio context, and provides that context to Gemini before generating an answer.

The general workflow is:

Recruiter Question
→ Generate Embedding
→ Pinecone Vector Search
→ Retrieve Relevant Portfolio Context
→ Provide Context to Gemini
→ Generate Grounded Answer

VECTOR EMBEDDINGS AND VECTOR SEARCH

Abhinav has hands-on project experience with vector embeddings and semantic vector search.

In the Ask Abhinav project, portfolio knowledge files are divided into smaller chunks and converted into numerical vector representations using Gemini embeddings.

The resulting embeddings are stored in Pinecone and searched using semantic similarity to retrieve information relevant to a recruiter's question.

The project uses the Gemini embedding model gemini-embedding-001, producing 3072-dimensional vectors compatible with the project's Pinecone index.
