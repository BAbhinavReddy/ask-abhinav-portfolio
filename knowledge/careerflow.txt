PROJECT: CareerFlow AI API

CareerFlow AI API is a backend application designed to help users track job
applications and analyze job descriptions using AI.

The backend was built with Python and FastAPI.

The application uses PostgreSQL as its relational database and SQLAlchemy
for database interaction.

Pydantic is used for request and response validation.

The application includes authentication and protected API functionality.

A user can provide a job description, which is analyzed using a connected
LLM API. The system extracts useful information from the job description,
such as the role and required skills.

The project also includes functionality for evaluating how well a resume
matches a job description.

The AI integration uses Google Gemini through the LangChain ecosystem.

The project demonstrates backend API development, database integration,
Pydantic validation, authentication, and integration of AI capabilities into
a Python backend application.

The project was primarily developed as a backend API rather than as a
complete frontend application.
